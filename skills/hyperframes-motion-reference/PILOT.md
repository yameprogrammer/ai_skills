# 5초 모션 파일럿: Code & Melody 곡명 카드

- 작업 파일은 프로젝트 내 실험용 폴더에 두고 실제 릴리즈에는 넣지 않는다. 기존 로고·텍스트·사용 승인된 폰트만 사용. 외부 템플릿은 필수가 아니다.
- 1920×1080 / 30fps / 150프레임. 소리 없는 5초 카드 한 장. 검은 남색 배경, 배경에 얕은 앰버 빛, 좌측 정렬 타이틀.
- 0.0–0.5초: 배경이 먼저 들어온다. 0.5–1.1초: 제목이 짧게 나타난다. 1.1–4.4초: 움직임 없이 제목을 읽게 한다. 4.4–5.0초: 배경과 글자가 같이 빠진다.
- 같은 입력으로 HyperFrames와 기존 Remotion 한 번씩. 첫 시도와 재렌더 시간은 나눠 기록하고, 곡명 한 줄과 비율을 바꾸기 쉬운지도 비교한다.
- 첫·중간·끝 프레임과 320px에서 한글이 잘리지 않는지 본다. 실제 작업에 채택할 때만 KO/EN/JA 자산을 준비한다. 작업용 소스, 로컬 렌더 출력, 버전 메모를 남긴다. 게시하지 않는다.
